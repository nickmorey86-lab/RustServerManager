# Rust Server Manager

## Purpose

Rust Server Manager is a desktop application intended to provide a complete management solution for Rust server owners.

### Core Goals

- Install and configure Rust servers
- Install and manage Carbon or Umod
- Manage plugins
- Monitor server status
- Administer players
- Execute RCON commands
- Customise application themes

## Main Tabs

- Dashboard
- Server Info
- Player Admin
- Carbon Installer
- Umod Installer
- Server Installer
- Plugin Manager
- Console
- Settings

## Future Architecture Decision

Carbon Installer and Umod Installer are likely to be merged into a single Framework Manager.
